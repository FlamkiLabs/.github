# Flamki Labs

Engineering data for frontier AI.

Flamki Labs is an independent AI data and evaluation company building repository-level software engineering datasets, reproducible task environments, and coding-agent evaluations.

## Research

[HorizonSWE](https://flamkilabs.com/horizonswe) is our research programme for repository-level coding-agent evaluation. Pilot 01 publishes aggregate outcomes, methods, and a preliminary technical report. Long-horizon evaluation is the research focus; independent horizon and broader benchmark validation remain outstanding.

Task prompts, hidden tests, reference solutions, and generated patches remain private. Public results distinguish graded outcomes from generation limits and service errors.
